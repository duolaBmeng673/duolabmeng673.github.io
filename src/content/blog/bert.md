# BERT

# 1\.Abstract\&Introduction

源自Transformers的双向编码表示\(Bidirectional Encoder Representations fromTransformers\)，简称为BERT，是该论文团队提出的一种新的基于Transformers的模型架构，其具有以下优点：

1\.添加一个额外的输出层即可进行微调

2\.在概念上简单，指标表现优异

如今预训练模型在下游任务的应用主要有两个策略：基于特定任务训练模型和引入最小特定于任务的参数并进行微调，二者的相同点是使用单项语言模型来学习通用语言表示。在本文中，编者提出BERT来改进微调的方法：类似于完形填空的”掩码语言模型\(MLM\)”，综合分析上下文来突破性实现预训练的双向性

该文章有以下贡献：

1\.展示了双向预训练对语言表示的重要性；实现了预训练的深度双向表示

2\.作为基于微调的大模型，BERT的性能优于许多特定于任务的架构

3\.BERT提高了11个NLP任务的最新技术水平；代码开源，预训练开放

下图是BERT，OpenAI GPT，ELMo三个模型的架构差异。个人理解为BERT每个token均受其上下文tokens影响；而GPT中每个token仅受上文所有tokens影响；ELMo将从左到右和从右到左的过程分别放在两个框架之内，似乎每个token仅受上一个token和下一个token影响。

# 2\.Related work

本节主要回顾了对模型的预训练方法的历史

## Unsupervised Feature\-based Approaches

预训练的单词嵌入是当前NLP系统的一个重要组成部分，此方法使用从左到右的语言建模目标，从上下文的角度判断用词的正误。

ELMo将词嵌入研究概括为不同的维度，推出了几个主要NLP基准测试的最新技术。

可以看出，这些研究方法均是基于特征的且具有单向性。

## Unsupervised Fine\-tuning Approaches

生成上下文表示的句子或文档编码器从未标记文本进行预训练，并根据特定任务进行微调，这样做的好处是需要学习的参数数量少，利用此方法的OpenAI的GPT已经取得了很好的成效。

## Transfer Learning from Supervised Data

从有监督学习数据中进行有效迁移学习在大型预训练模型任务中也非常重要

2\.参数设置如表所示：

**对下图，论文有如下解释：**

1\.构建BERT框架有两个步骤：预训练和微调。预训练采用不同于训练任务的未标记数据；微调在同一参数初始化之后对下游任务的标记数据进行微调得到多个模型，每个下游任务都有单独的微调模型。

2\.为使BERT能够应对各种下游任务，将输入明确表示为单个句子和一对句子，“句子\(sentence\)”可以使连续文本的任意跨度，而不是实际的语言句子。编者使用WOrdPiece嵌入和30000个标记词汇，每个序列的第一个标记是特殊的分类标记，该标记对应的隐藏分类状态用作分类任务的聚合序列显示。

3\.句子被打包成一个序列，以两种方法区分句子：首先，用特殊序列\[SEP\]分开；之后为每个标记添加一个学习嵌入，表示其句子归属\(A\\B\)，将输入嵌入表示为E，特殊\[CLS\]令牌的最终隐藏向量表示为C，第i个输入标记的最终隐藏向量表示为Ti。

## 3\.1 Pre\-training BERT

### Task 1:Masked LM

为训练深度双向表示，团队对一定比例的输入tokens进行随机遮蔽，这项流程被称为"Masked LM\(MLM\)"，类似于完形填空。此任务中，编者对WordPiece tokens随机进行15%的遮蔽。与去噪声自动编码器不同的是，模型仅预测遮蔽单词而不是输出完整文本。

这样做的一个坏处是：预训练中的遮蔽在微调过程中未出现导致预训练和微调之间出现不匹配。为了减轻这一现象，训练数据生成器选择以下策略：

1\.80%的时间将待遮蔽单词替换成\[MASK\]

2\.10%的时间将待遮蔽单词替换成随机token

3\.10%的时间使待遮蔽单词不变

之后Ti将用于预测具有交叉熵损失的原始标记。

这样做的好处是：使Transformers编码器不知道哪些单词被随机单词替换而强迫保留每个单词的上下文表征。同时，模型的语言理解能力不受影响。

### Task 2:Next Sentence Prediction \(NSP\)

NSP任务涉及对两句子之间关系，语言模型并不能捕捉到这样的关系，为了训练一个能理解句子之间的关系的模型，在生成训练集时，对于相邻的句子A与B，有50%的时间B是A的实际的下一个句子，50%的时间B是语料库中的随机句子，上文图中"C"用作下文预测

### Pre\-training data

预训练语料库使用BooksCorpus和英语维基百科，对维基百科语料库进行一定的筛选。

## 3\.2 Fine\-tuning BERT

将特定于任务的数据（包含输入和输出）插入BERT中并进行端对端的微调参数。将句子A换成句子对中的第一个，将句子B换成句子队中的第二个，类比问答句子对就是\[A:Question ; B:Answer\]

在输出中，令牌表示被馈送到输出层以进行令牌级任务（例如序列标记或问答），\[CLS\]表示被馈送到输出层进行分类。

# 4\.Experiments

## 4\.1 GLUE

通用语言理解评估\(The General Language Understanding Evaluation\)，简称GLUE，是各种自然语言理解任务的集合。

微调过程中引用分类层权重W\(K\*H\)来作为新参数（K为标签的数量），并以第三部分中输入序列中第一个输入标记\[CLS\]的最终隐藏向量C\(H\*H\)作为聚合表示，利用C和W计算标准分类损失为log\(softmax\(C\*WT\)\)

设batch size为32，每三轮对所有GLUE任务数据进行微调。经过一系列步骤得到最终的BERT\(BASE\)和BERT\(LARGE\)。由下图可知模型表现优异，附录B\.1对MNLI，QQP等数据集做出了详细解释。

![image\.png](/articles/bert/image.png)

## 4\.2 SQuAD v1\.1\&v2\.0

斯坦福问答数据集\(The Stanford Question Answering Dataset\)，简称SQuAD，是大量众包问答对的集合，v2\.0中的问答更加现实。

在v1\.1数据集中，BERT作为单个系统，表现最好的模型优于排行榜最佳系统\+1\.5 F1 和 \+1\.3 F1，且优于顶级集成系统。

在v2\.0数据集中，团队简单拓展了SQuAD v1\.1 BERT模型来完成这项任务。

# 5\.Ablation Studies

消模实验\(Ablation Studies\)是指通过删除模型或算法的某种特征，并将其结果与原模型或算法作对比，来观察或验证该特征的有效性及其作用。

## 5\.1 Effect of Pre\-training Tasks

实验组为证明NSP的影响，采用标准的Left to Right\(LTR\)LM而不是MLM，未调试也仅利用了左侧约束。实验结果显示LTR LM的性能显著低于MLM。

## 5\.2 Effect of Model Size

实验组通过训练许多不同层数\(L\)、隐藏单元\(H\)和注意力头\(A\)的 BERT 模型来观察模型大小对微调任务准确性的影响。

实验组证明扩展模型的大小，能够提升模型处理任务的能力，即使非常小规模的工作也能通过扩展模型规模来得到明显提升。同时，他们假设如果对一个模型进行针对于特定下游任务的微调，即使使用非常少量的随机初始参数，也能使模型性能得到提升。

## 5\.3 Feature\-based Approach with BERT

将BERT模型应用到CoNLL\-2003 NER任务上，不进行微调以生成基于特征的BERT模型，根据结果可知，BERT模型对基于特征方法和微调方法均有效。

# 6\.Conclusion

通过将迁移学习，无监督预训练从单项架构拓展到深层双向架构，模型性能获得明显提升，能够广泛解决NLP任务。
