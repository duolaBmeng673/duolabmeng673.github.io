# TableQuest

# Abstract \& Introduction

TableQuest是新的基准测试，旨在评估LLM在各种复杂场景中对表格数据的理解和推理能力。

作者将表格问题根据不同类型和难度分成了三个等级：1、信息提取（简单）；2、运算（中等）；3、分析（困难）

在对TableQuest的评估中，作者探索了各种llm的性能，当处理复杂任务时，很多模型会出现错误，同时当序列较长、应用特定领域知识和推理时，模型的不足会进一步突出。

# TableQuest

数据直接来自SEC的EDGAR数据库，这些数据具有详细的HTML注释，HTML注释能够捕捉层次结构和详细单元格信息。采用HTML格式的原因主要是: 1\.相比于其他自然语言，它可以更好的保留表结构；2\.互联网是LLM预训练语料库的重要来源。

为了解决当前问答数据集的同质性，作者设计了渐进式三轮聊天格式，其中每一轮都建立在前一个之上，从而产生一系列问答对，这样做能够提高模型的相应范围。此外，结合了明确的思维链\(CoT\)提示来引导模型阐明其推理步骤，这有利于更彻底的质量检查。

考虑到问题的难度，作者采用人机混合验证方法来验证问题与答案的相关性、合理性和有效性。

# Experiments

从合成数据集中抽取240个问题，每个难度有80个表作为基准评估子集，每个问题有生成提示以及答案格式化引导。

实验测试了7个模型，利用一些流行的评估指标包括EM、F1、BLEU等，此外，除了字段的精确匹配，作者还使用机器法官\(machine judge?\)来对长格式答案进行可解释的和灵活判断。具体来说，对于分析任务，我们将每个模型对基线的响应进行比较，要求判断模型 \(gpt\-4\-turbo\) 推理哪个模型更准确、逻辑和清晰的输出。
