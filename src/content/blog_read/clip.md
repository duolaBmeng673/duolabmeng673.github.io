# CLIP

# Abstract\&Introduction and Motivating Work

此前的最先进的计算机视觉模型通过预测一组固定的预定对象识别来训练，由于每种图像概念需要特定的标记数据，这种方法有着巨大的限制。

该论文编者提出直接从关于图像的原始文本学习，并证明了“预测图像与文字的相关性”是有效的和可拓展的训练方法。另外，由于机器学习了视觉概念的语言表达，这些模型也能进行零样本的迁移学习且性能具有竞争力。

文本学习的预训练方法给NLP带来了巨大的发展，GPT3证明了不用高质量的有标记NLP数据集也能带来不错的模型性能。然而在计算机视觉领域，标准做法仍然是利用标记数据集进行预训练。论文编者进行联想和拓展，提出直接从网络文本学习的可拓展预训练方法可能为计算机视觉带来相似的突破。

然而，利用自然语言监督进行图像表征学习仍然很少见，其主要原因在于利用此种训练方法得到的模型零样本迁移学习表现不尽人意。如果想提升模型的零样本迁移学习的性能，需要更高质量的数据集。此外，静态softmax分类器检测机制缺乏动态输出能力，限制了模型零样本迁移学习的能力。

本篇论文中，编者意在研究大规模的利用自然语言监督训练的图像分类器的行为，构建了4亿的图像\-文本对数据集并演示了从头开始训练的ConVIRT简化版本，给其起名为CLIP，可用于“对比语言\-图像训练\(Contrastive Language\-Image Pre\-training\)"，是一种从自然语言监督学习的有效方法。

性能方面，CLIP在保证了在零样本迁移学习任务上有比肩许多特定于任务的有监督模型的高准确率的同时，还具有更高的稳定性和计算效率，这种综合性能是有监督ImageNet模型无法比拟的。

# Approach

## Natural Language Supervision

此节中，编者强调将自然语言当做一种训练符号。同时指出，从自然语言学习具有如下优点：

1. 易拓展性：这种方法不需要以经典的“机器学习兼容格式”注释，可以从互联网中的大量文本学习。

2. 可迁移性：模型不学习图片表征而是学习图片和文本之间的联系，有利于零样本迁移学习。

## Creating a Sufficiently Large Dataset

现存的广泛使用的数据集都有：MS\-COCO, Visual Genome, YFCC100M\. 前二者数据量不足而后者质量参差不齐。最终决定自行构建数据集，该数据集包含4亿个图片\-文本对并尽可能包含多的视觉概念。

## Selecting an Efficient Pre\-Training Method

![image\.png](/articles/clip/image%205.png)

最初团队打算从头开始联合训练图像CNN和文本transformer来预测图像的标题，但结果并不是很可观。根据上图显示，Transformer语言模型学习识别ImageNete类要比一个更简单的预测相同文本的词袋编码慢三倍，同时计算量也比较大。

团队发现上述方法都是预测每个图片文本的具体单词，这显然是一项困难的任务。综合对比之后，他们探索了一个更容易的任务：只从整体角度预测哪个文本和哪个图像配对。在词袋编码模型的基础上，将预测目标切换成对比目标，结果如图\[Bag of Words Contrastive\]显示其零样本迁移学习效率进一步提升了四倍。

该节给出了预训练方法解释：

1. 给定N对图片\-文本对，训练CLIP使其预测N\*N个图片\-文本对中可能发生的N个，N\*N个对的分配如图所示：

![image\.png](/articles/clip/image%206.png)

2. 联合训练图像编码器和文本编码器以最大化每批中N对真实对的图片文本嵌入的余弦相似度，同时最小化\(N\*2\-N\)个有误对嵌入的余弦相似度，并在这些相似度分数上优化了对称交叉熵损失。

3. 利用线性映射，将每个编码器表征映射到多模态嵌入空间。

4. 删除文本变换函数t\(u\)，简化图像变换函数t\(v\)

5. 在训练期间直接优化控制softmax中 logits 范围的温度参数τ，作为对数参数化乘法标量，以避免作为超参数调试。

## Choosing and Scaling a Model

1. 图片编码器方面，有两个不同架构的图片编码器：

    1. 使用ResNet\-50作为编码器基础架构并稍加修改，并用注意力池机制替换全局平均池化层，同时注意力池层被实施为transformers型多头QKV注意力单层，其中查询是图像的全局平均池化表征。

    2. 使用Vision Transformer\(ViT\)。以此架构为基础，对transforemrs之前的组合补丁和位置嵌入添加额外的层归一化，并使用略有不同的初始化方案。

2. 文本编码器方面，使用改进架构的Transformer。

3. 扩展模型方面：

    1. 对于ResNet图像编码器，参考Tan \& Le \(2019\)方法，使用一个简单的基线来平均分配额外的计算以增加模型的宽度、深度和分辨率

    2. 对于文本编码器，仅缩放模型的宽度并使其与ResNet宽度的计算增加成正比。

## Training

训练5个ReaNets和3个Vision Transformers，前者包含ReaNet\-50, ResNet\-101, RN50x4, RN50x16和RN50x64；后者包含ViT\-B/32, ViT\-B/16和ViT\-L/14。使用Adam优化器，并对超参数初始化、温度参数和硬件等进行合理部署。

# Experiments

## Zero\-Shot Transfer

### Using CLIP For Zero\-Shot Transfer

CLIP预训练方式为预测图像和文本片段是否在数据集中配对。对于每个数据集，将可能文本打包为集合，通过它们各自的编码器计算图像的特征嵌入和可能文本集的特征嵌入，之后计算嵌入的余弦相似度，按照温度参数τ缩放，通过softmax函数归一化为概率分布。

CLIP预训练的每一步都可被视为优化随机创建的代理对计算机视觉数据集的性能。对于零样本评估，一旦文本编码器计算并对所有后续预测重用它，我们就缓存零样本分类器。这允许生成它的成本在数据集中的所有预测中摊销。

## Robustness to Natural Distribution Shift 自然分布变化的鲁棒性

此前发表的模型由于其相关性和模式真实性存疑的特征，常常被发现在一些其他数据集上的泛化能力不足，即在分布变化的情况下发现性能不及预期。CLIP模型为解决该问题带来了新的可能。

测量CLIP模型在适应ImageNet分布的性能变化后，发现其总体准确度提高9\.2%，而分布变化的平均准确率稍有下降且监督适应的准确性的提高紧密地集中在ImageNet分布周围，这引发了编者的一系列疑问，问题仍待解决。

实验显示零样本CLIP提高了有效鲁棒性且零样本 CLIP 明显优于具有等效 ImageNet 性能的小样本模型。

# Limitations

CLIP如今仍具有很多局限性：

1. 在带有训练拆分的数据集上，CLIP的零样本表现与现有最先进的技术仍然有差距。

2. CLIP在几种类型的任务上的表现相当弱，例如CLIP 在区分汽车模型、花种类和飞机变体等几种类型的细粒度分类上的性能很差；CLIP也很难处理更加抽象和系统性任务等。

3. CLIP的高性能几乎被限制在分类任务中，在生成式任务中表现受到限制。

4. CLIP深度学习效率较低。

5. 迁移学习数据集总量有限，无法完美复现零样本学习；缺乏更加公正客观的评估数据集。

6. 训练数据集未经过滤和整理，导致CLIP出现许多社会偏差。

7. CLIP未对少样本学习性能进行优化，未来可将零样本学习和少样本学习结合以提高CLIP性能。

# Broader Impacts

## 积极影响

该论文评估了CLIP的性能和适应度，以及它在上下文分析的更广泛的影响。此外，通过将CLIP针对特定功能进行定制可以解锁各种新应用程序；CLIP降低了AI应用开发的门槛，降低了数据获取成本。

## 潜在挑战

CLIP训练数据来自互联网，可能包含社会偏见；CLIP零样本学习效率较低，需要大量计算资源……（剩余缺点在\[6\.Limitaions\]提及）

# Conclusions

CLIP引用了NLP中任务无关模型预训练的成功并在计算机视觉领域带来了巨大的性能提升。在足够的尺度上，模型的性能可以与特定于任务的有任务模型竞争，同时未来还有很大的改进空间。
