## 一、整体骨架

| 层级 | 规范 |
| --- | --- |
| 交付形式 | 一整块 markdown 代码块 |
| H1 | 主题名 + 括号内的核心算法名 |
| H2 | 数字编号，章与章之间用 `---` 分隔 |
| H3 | 每个概念一节，细分用 H4 |
| 顺序 | 概览 → 概念；**涉及计算的主题**再加：做题步骤 → 例题 |

概览只回答四件事：它是什么、怎么构建、什么时候停止、**核心问题**是什么。

## 二、概念部分的写法

1. **先放完整例题数据**：概念部分一开头就摆出数据表，所有概念都在这份数据上举例，沿用同一个例子。
2. **先符号，后公式**：先给"符号 | 含义"表（关键词加粗），再给一张实例化表，把符号落到具体数据上；计算约定放进引用块。
3. **每个概念块的固定模板**：
   - 标题 = 圈号 + 名称 + 符号（**不再加大白话问句**）
   - 独立公式
   - 加粗标签的要点：**算法** / **意义**（需要时加 **缺点**）
   - 在例题数据上的具体计算
4. **公式里每个符号都要解释**：写在公式正下方，用大白话说明下标、求和号、分母各自是什么，用例子代入，再加一句"如果是三类就多一项"这样的延伸。
5. **易混概念放对比表**：紧跟在相关概念后面，列"数的是什么 | 例子"，再补两条要点说明区别。
6. **圈号 ①–⑤ 当固定标签**：步骤、计算表、交叉引用都用同一套。
7. **不写 PPT 叫法，也不标 PPT 页码**。

## 三、仅涉及计算题的规范

**做题步骤与例题**

- 概念之后单独一节做题步骤，编号列表，关键词加粗，引用圈号。
- 例题开头用加粗的 **题目** 一行。
- 数据表**完整给出，不简写**。
- 步骤 1 是数个数表（取值 | 样本数 | 各类个数 | 样本编号），步骤 2 是计算表（量 | 计算 | 结果）。

**计算书写**

- 公式 → 代入 → 结果，三步都写，零项也写出来（如 $0/2$ 的形式）。
- 至少拆开一个子项逐项写，如 $0.5288+0.4422$。
- 计算格里用括号补一句说明。
- 先完整算一个属性，其余写"同理"并给汇总表。
- 同一例题内小数位统一；结果加粗；被选中的行加粗并标"← 最大"；决定用一句加粗的话写出。

**表格**

- 个数写成"类别一/类别二"，表前先说明。
- 紧凑格式：`取值 样本数（a/b）· 取值 样本数（a/b）`。
- 分组表里重复的第一列留空，数值列可右对齐。

## 四、可选内容

逐层递归的分步演示（每层一个 H3、子数据集保留原编号、说明已排除的属性）、最终结果树和 if-then 规则列表，**只在主题需要时写，可有可无**。

## 五、SVG 设计规范（重点）

> 保留原有三条核心意图（**文字不压线、颜色按角色分配、元素不越界**），并收口为可量化、可自动检查的 v1 规范；配套静态校验见 [tests/svg-style.test.mjs](../../tests/svg-style.test.mjs)，无头 Chrome 布局校验见 [scripts/lint-svg.mjs](../../scripts/lint-svg.mjs)。

### 5.1 画布

- `viewBox` 宽度统一 **`760`**，高度按内容定、**不超过 `520`**。
- 所有可见元素（含底部说明、公式条）距四边至少 **`24`**。
- 坐标取 **`4` 的倍数**，主要布局取 **`8` 的倍数**。
- SVG 内**不画整幅背景矩形**，沿用 `<img>` 容器的白底卡片。

### 5.2 字体

- **字族**：`'PingFang SC','Noto Sans SC','Microsoft YaHei',system-ui,sans-serif`，不使用外部字体。
- **字号（仅四档）**：`12`（脚注、时间标注）、`14`（节点文字、箭头标签）、`16`（分组标题）、`18`（图标题）。
- **字重（仅两档）**：`400` 与 `600`。图标题和节点标题用 `600`，其余用 `400`；**禁止整图加粗，禁止 `700` / `800`**。
- 多行行距 **`20`**（14 号字），居中用 `text-anchor="middle"`。
- **文字宽度估算**：中文与全角标点按 `字号 × 1.0`，英文数字按 `字号 × 0.6`；节点宽度 = `文字宽度 + 左右各 16`，向上取 `8` 的倍数。

### 5.3 颜色（严格限定下表，禁止其他十六进制色值）

| 角色 | 填充 | 描边 | 文字 |
| --- | --- | --- | --- |
| 中性（默认） | `#f8fafc` | `#94a3b8` | `#1f2937` |
| 主动方 / 发送方 | `#eff6ff` | `#3b82f6` | `#1e40af` |
| 响应方 / 目标 | `#f0fdfa` | `#14b8a6` | `#115e59` |
| 异常 / 冲突 / 攻击 | `#fef2f2` | `#ef4444` | `#991b1b` |
| 辅助 / 计时 / 提示 | `#fffbeb` | `#f59e0b` | `#92400e` |

- 次要文字统一用 **`#4b5563`**，不得更浅。
- 颜色只表示角色而非装饰；同一角色在所有图中保持同一颜色，**单张图最多使用 3 种强调色加中性**。**角色一致性优先于“最多 3 种强调色”**（当同一张图同时存在 4 种明确语义角色时允许并用，不得为凑数改变已有角色色）。
- 站点暗色主题对 SVG 应用 `invert(0.92) hue-rotate(180deg) contrast(1.08) brightness(1.05)` 滤镜；上表所有文字配色在亮／暗模式下对比度均须 **`≥ 4.5:1`**。

### 5.4 线条与形状

- **描边粗细（仅三档）**：`1`（辅助线、生命线）、`1.5`（默认）、`2`（强调）；**禁止 `3px` 及以上粗边**。
- **圆角**：节点 `rx="8"`，分组 `rx="12"`。分组用虚线边框（`stroke-dasharray="6 4"`），标题位于分组内左上角、距边 **`16`**。
- **箭头**：每张图只定义一个 `<marker>`，`id` 加文件名前缀（如 `arp-arrow`）。
- **虚线**：只用于“虚线箭头表示广播 / 可选 / 逻辑关系”时，图中须有一句图例说明；**时序图的生命线虚线与分组边框虚线不需要图例**。

### 5.5 连线与标签

- 连线只允许**水平、垂直或 90° 折线**；除非语义本身是倾斜（如传播时延示意），且同一张图所有斜线坡度一致。
- **标签不得压在任何线上**：标签放线的上方居中，距线 **`≥ 6`**；空间不够时把线断开，或给标签配与背景同色、内边距 `4` 的底块。
- **任意两个文字包围盒不得相交**；文字与非所属图形描边距离 **`≥ 6`**。
- 节点内文字距节点边：**上下 `≥ 8`，左右 `≥ 16`**。连线不得穿过其他节点，除非语义明确为“穿透”并加注。

### 5.6 时序图模板（CSMA/CD、RTS/CTS 等）

- 顶部参与者框，下方垂直生命线（`stroke-width="1"`、`#94a3b8`、虚线），须有明确终点。
- 消息箭头一律**水平**，行距固定 **`56`**，标签在箭头上方居中；传播时延用旁注表达，不靠画斜线。
- 左侧留 **`72`** 宽的时间 / 间隔列，`DIFS`、`SIFS` 等画成时间列里的小括号加标签，不浮在箭头上。
- 激活段（如 `NAV` 推迟访问）画成生命线上宽 **`12`** 的细条，说明文字放在细条右侧。

### 5.7 说明与公式

- 图底部的公式条、总结句优先移出 SVG、放进笔记正文；必须留在图里时，做成距四边 **`≥ 24`** 的注释块，最多两行，宽度不超过 `760 - 48 = 712`。

### 5.8 无障碍与结构

- 每个 SVG 必须带 `role="img"`、`<title>`、`<desc>`。
- 文字一律是真实 `<text>`，不转成路径；无 CSS 动画、无外部引用，文件内 `id` 唯一。

**HTML 演示**只在复杂算法时才做（点击逐步演示），简单主题不需要。

## 六、语言与排版

- 数学用 LaTeX。
- 中文短句，关键术语加粗。
- 表情符号只在你自己加时出现，**不用 🟨**。

## 七、刻意不写的内容

勘误 / PPT 错误总结、速记 / 自测题、额外的算法变体（除非你要）、PPT 里的习题和 tips 页。

## 八、与以往笔记共通

- 笔记以基本概念、运作方式、核心作用为主。
- 配图习惯：SVG 图示，必要时拆成独立 SVG 文件。
- 例题数据沿用 PPT 的原例；每个表或结构用一句话说明作用。
