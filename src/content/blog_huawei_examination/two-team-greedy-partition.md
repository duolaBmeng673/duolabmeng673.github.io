# 从频次约束到最优划分

## 1. 问题描述

给定一个包含偶数个正整数的序列，需要将所有元素划分为两支人数相同的队伍 `n1` 和 `n2`，满足以下条件：

- 每支队伍内部的数字不能重复。
- 两支队伍都按升序输出。
- 如果存在多种合法划分，要求 `n1` 的元素和最小。
- 如果无法完成划分，输出 `null`。

输入格式存在一个特殊约定：去除输入首尾空白后，如果剩余内容不包含空白字符，则将每个数字字符分别视为一个整数。例如，输入 `1234` 表示序列 `[1, 2, 3, 4]`；否则，按照空白字符分隔整数。

这道题表面上是一个集合划分问题。如果直接考虑所有元素的分配方式，就会涉及大量组合。但仔细分析约束后，可以发现：**一部分元素的分配方式是固定的，真正需要优化的只有剩余部分。**

## 2. 从约束出发：什么时候无解？

首先考虑单个数字在两支队伍中的分配方式。

由于每支队伍内部都不允许出现重复数字，一个数字在每支队伍中最多出现一次。因此：

- **出现一次：** 可以分配给任意一支队伍。
- **出现两次：** 必须分别分配给两支队伍。
- **出现三次及以上：** 无论怎样分配，都无法满足队内不重复的要求。

第三种情况直接给出了无解条件：

$$
\exists x,\ \operatorname{freq}(x)>2
\quad\Longrightarrow\quad
\text{无解}
$$

因此，没有必要在分配过程中反复检查队内是否重复。只需要在开始阶段统计每个数字的出现次数，就能提前判断是否存在解。

为了方便统计，先将原序列升序排序。这样，相同的数字会连续出现，可以通过一次线性扫描完成频次统计。

## 3. 关键观察：重复数字的分配已经确定

假设所有数字的出现次数都不超过两次，那么可以将它们分为两类。

### 3.1 出现两次的数字

假设数字 `x` 出现两次。

因为两支队伍内部都不能出现重复数字，所以两个 `x` 必须分别进入 `n1` 和 `n2`。

例如：

```text
原序列：1 2 2 3 3 4

固定分配：
n1：2 3
n2：2 3
```

无论最终选择哪种合法方案，这部分分配都不会改变。

更重要的是，重复数字对两支队伍的元素和贡献完全相同。因此，在比较不同方案时，这部分可以视为固定常量，不会影响 `n1` 与其他方案之间的优劣比较。

代码使用 `duplicate` 保存每个重复数字的一个代表值，后续再将它分别加入两支队伍。

这里保存一个代表值并不意味着丢弃原序列中的副本：一个出现两次的数字，最终会向 `n1` 和 `n2` 各贡献一个元素。

### 3.2 只出现一次的数字

只出现一次的数字没有固定的分配方向，可以自由进入任意一支队伍。

这部分才是真正需要优化的对象。

设原序列长度为 $n$，每支队伍需要容纳：

$$
k=\frac{n}{2}
$$

个元素。

如果出现两次的不同数字共有 $d$ 个，那么它们已经占据每支队伍中的 $d$ 个位置。因此，每支队伍还需要分配：

$$
r=k-d
$$

个只出现一次的数字。

由于原序列长度为偶数，而每个出现两次的数字贡献两个元素，所以只出现一次的数字总数也必然是偶数。在满足可行性条件时，这些数字可以平均分配给两支队伍。

至此，原问题已经被简化：

> 固定所有重复数字的分配，只需要将只出现一次的数字均分为两组，并使 `n1` 的元素和最小。

## 4. 贪心策略：将较小的一半分给 n1

设只出现一次的数字经过排序后为：

$$
u_1\le u_2\le \cdots\le u_{2r}
$$

每支队伍需要从中选择 $r$ 个数字。

为了使 `n1` 的元素和最小，直观上应该将较小的数字分配给 `n1`，将较大的数字分配给 `n2`。

这一策略可以通过交换论证严格说明。

假设某个方案中，`n1` 选择了较大的数字 $b$，而 `n2` 选择了较小的数字 $a$，并且：

$$
a<b
$$

由于 $a$ 和 $b$ 都只出现一次，交换它们的归属不会造成队内重复，也不会改变两支队伍的元素数量。

交换前，`n1` 包含 $b$；交换后，`n1` 改为包含 $a$。因此，`n1` 的元素和减少：

$$
b-a>0
$$

这说明：只要 `n1` 仍然包含某个较大的数字，而 `n2` 包含比它更小的数字，就可以通过交换进一步降低 `n1` 的元素和。

所以，最优方案必然可以整理为：

- `n1` 选择最小的 $r$ 个只出现一次的数字。
- `n2` 选择剩余最大的 $r$ 个只出现一次的数字。

也就是说：

$$
n1_{\text{unique}}=[u_1,\ldots,u_r]
$$

$$
n2_{\text{unique}}=[u_{r+1},\ldots,u_{2r}]
$$

**这就是本题的核心：固定部分不参与优化，剩余部分通过排序直接得到最优划分。**

不需要枚举组合，也不需要动态规划。

## 5. 算法实现

整体流程如下：

1. 解析输入，根据输入中是否存在空白字符选择对应的解析方式。
2. 对原序列排序，使相同数字连续出现。
3. 扫描序列，统计每个数字的出现次数。
4. 如果任何数字出现超过两次，直接输出 `null`。
5. 将数字分为 `unique` 和 `duplicate` 两类。
6. 计算每支队伍还需要分配的唯一数字数量 $r$。
7. 将 `unique` 从中间切分，较小的一半分给 `n1`，较大的一半分给 `n2`。
8. 将 `duplicate` 分别加入两支队伍，最后排序并输出。

### Python 代码

```python
import sys

def solve():
    s = sys.stdin.read().strip()

    if not s:
        return

    # 处理输入格式
    if any(c.isspace() for c in s):
        nums = list(map(int, s.split()))
    else:
        nums = [int(c) for c in s]

    nums.sort()

    n = len(nums)
    k = n // 2

    unique = []
    duplicate = []

    i = 0

    while i < n:
        j = i + 1

        # 统计 nums[i] 连续出现的次数
        while j < n and nums[j] == nums[i]:
            j += 1

        count = j - i

        if count > 2:
            print("null")
            return
        elif count == 1:
            unique.append(nums[i])
        else:
            duplicate.append(nums[i])

        i = j

    # 每队还需要分配的唯一数字数量
    r = k - len(duplicate)

    if r < 0 or len(unique) != 2 * r:
        print("null")
        return

    # unique 已经按升序排列
    n1 = unique[:r] + duplicate
    n2 = unique[r:] + duplicate

    n1.sort()
    n2.sort()

    print(*n1)
    print(*n2)

if __name__ == "__main__":
    solve()
```

## 6. 正确性分析

可以分别从可行性和最优性两个角度进行证明。

### 6.1 可行性

如果某个数字出现超过两次，由于它在每支队伍中最多出现一次，两支队伍合计最多容纳两个副本。因此，原问题无解，程序输出 `null` 正确。

如果所有数字出现次数均不超过两次，那么：

- 每个出现两次的数字分别加入两支队伍，不会造成队内重复。
- 每个只出现一次的数字只会被分配到其中一支队伍，不会造成队内重复。
- 每支队伍包含相同数量的重复数字，以及相同数量的唯一数字。

因此，在数量关系合法时，两支队伍都恰好包含 $k$ 个元素，并且原序列中的所有元素都被分配完毕。

### 6.2 最优性

所有出现两次的数字都必须分别进入两支队伍，因此它们对 `n1` 的元素和贡献固定。

所以，最小化 `n1` 的总和等价于最小化它所获得的唯一数字之和。

程序将唯一数字按升序排列，并把最小的 $r$ 个分配给 `n1`。根据交换论证，任何包含更大数字、却遗漏更小可选数字的方案，都可以通过交换进一步降低 `n1` 的元素和。

因此，程序得到的方案是所有合法方案中 `n1` 元素和最小的方案。

## 7. 示例分析

### 示例一：存在重复数字

输入：

```text
1 2 2 3 3 4
```

频次分析：

| 数字 | 出现次数 | 分配方式 |
|---|---:|---|
| 1 | 1 | 自由分配 |
| 2 | 2 | 两队各一个 |
| 3 | 2 | 两队各一个 |
| 4 | 1 | 自由分配 |

每队需要 $3$ 个元素。重复数字 `2` 和 `3` 已经占据两个位置，因此每队还需要一个唯一数字。

唯一数字排序后为：

```text
1 4
```

为了最小化 `n1` 的元素和，将 `1` 分给 `n1`，将 `4` 分给 `n2`。

输出：

```text
1 2 3
2 3 4
```

### 示例二：连续数字串

输入：

```text
1234
```

根据题目规定，输入被解析为：

```text
1 2 3 4
```

所有数字都只出现一次。将较小的一半分给 `n1`，较大的一半分给 `n2`。

输出：

```text
1 2
3 4
```

### 示例三：无法满足队内不重复

输入：

```text
3 3 3 5 6 7
```

数字 `3` 出现三次，但两支队伍合计最多容纳两个 `3`。

因此直接输出：

```text
null
```

## 8. 复杂度分析

设输入元素个数为 $n$。

- 原序列排序：$O(n\log n)$。
- 扫描并统计频次：$O(n)$。
- 构造两支队伍：$O(n)$。
- 对两支队伍分别排序：总计不超过 $O(n\log n)$。

因此，总体时间复杂度为：

$$
\boxed{O(n\log n)}
$$

由于需要保存原序列以及分类后的数字列表，空间复杂度为：

$$
\boxed{O(n)}
$$

## 9. 思路总结

这道题值得记录的不是某种复杂的数据结构，而是如何从约束中提炼出最优解。

整个推导过程可以归纳为四步：

**第一步：判断可行性。**

每个数字在两支队伍中合计最多出现两次，因此任何数字出现超过两次都会导致无解。

**第二步：固定不可自由选择的部分。**

出现两次的数字必须一边一个，它们对两队元素和的贡献相同，不影响最优方案的比较。

**第三步：缩小优化范围。**

将固定部分剥离，只考虑出现一次的数字。原问题由一般的组合划分转化为对一组自由元素的选择问题。

**第四步：利用排序与交换论证。**

为了最小化 `n1` 的元素和，将最小的若干个唯一数字分给 `n1` 即可。

这是一种值得迁移到其他算法题中的思考方式：

> 不要急于枚举所有可能的方案。先分析约束是否固定了部分决策，再判断剩余部分能否通过排序、交换或其他性质直接确定最优解。
