# 最少机器覆盖业务需求：状态压缩 DP

## 1. 题目描述

有 `d` 台机器，每台机器可以提供 `w` 个能力条目。现在有一个业务需求，需要满足 `t` 个不同的能力条目。

每台机器都可以选择使用或不使用。选择若干台机器后，如果这些机器提供的能力条目的并集覆盖了全部业务需求，就认为业务可以被满足。

要求选择最少的机器数量。如果无论如何都无法覆盖全部需求，输出 `0`。

## 2. 样例

### 样例 1

输入：

```text
4 2 3
2 8
3 5
8 9
5 2
2 5 8
```

输出：

```text
2
```

需求集合是 `{2, 5, 8}`。例如第一台和第四台机器合起来可以覆盖全部需求，因此最少需要两台机器。

### 样例 2

```text
2 3 4
1 2 3
4 5 6
10 11 12 13
```

输出：

```text
0
```

两台机器提供的能力中没有任何条目属于需求集合 `{10, 11, 12, 13}`，所以无法满足业务。

## 3. 先明确 ACM 输入读取

完整程序使用：

```python
import sys


def solve():
    input = sys.stdin.readline
```

这里的 `input = sys.stdin.readline` 是重新给读取函数取一个短名字，并不是提前读取一行，也不会跳过任何数据。

后续每次调用 `input()`，实际调用的都是 `sys.stdin.readline()`，并且从当前输入位置继续读取下一行。

因此：

```python
d, w, t = map(int, input().split())
```

会读取第一行 `d w t`。这一行被完整消费后，输入位置移动到下一行。

接着：

```python
for _ in range(d):
    machines.append(list(map(int, input().split())))
```

会连续读取接下来的 `d` 行机器数据。循环结束后，再执行：

```python
needs = list(map(int, input().split()))
```

读取的就是下一行业务需求。数据不会被跳过，除非代码主动多调用了一次 `input()`，或者题目输入格式与读取逻辑不一致。

## 4. 读取原始数据

先读取机器数量、每台机器的条目数和需求条目数：

```python
d, w, t = map(int, input().split())
```

然后读取 `d` 台机器：

```python
machines = []
for _ in range(d):
    machines.append(list(map(int, input().split())))
```

最后读取业务需求：

```python
needs = list(map(int, input().split()))
```

对于样例 1，读取结果相当于：

```python
d = 4
w = 2
t = 3

machines = [
    [2, 8],
    [3, 5],
    [8, 9],
    [5, 2],
]

needs = [2, 5, 8]
```

## 5. 把需求映射到 bit 位

需求条目只有 `t` 个，因此可以给每个需求编号 `0` 到 `t - 1`：

```python
pos = {}
for i in range(t):
    pos[needs[i]] = i
```

样例 1 中的映射是：

```python
{
    2: 0,
    5: 1,
    8: 2,
}
```

也就是说，需求 `2` 对应第 `0` 位，需求 `5` 对应第 `1` 位，需求 `8` 对应第 `2` 位。三种需求都满足时的状态就是二进制 `111`。

## 6. 把每台机器转换成 bitmask

遍历每台机器提供的能力。如果某个能力属于需求集合，就把对应位置设置为 `1`：

```python
masks = []

for machine in machines:
    mask = 0

    for x in machine:
        if x in pos:
            mask |= 1 << pos[x]

    if mask != 0:
        masks.append(mask)
```

以样例 1 为例：

| 机器 | 覆盖的需求 | mask |
| --- | --- | --- |
| `[2, 8]` | `2、8` | `101` |
| `[3, 5]` | `5` | `010` |
| `[8, 9]` | `8` | `100` |
| `[5, 2]` | `5、2` | `011` |

不包含任何需求的机器没有贡献，可以直接丢弃。

### `|=` 的含义

```python
mask |= 1 << pos[x]
```

等价于：

```python
mask = mask | (1 << pos[x])
```

`|` 是按位或。某一位只要在旧状态或新状态中为 `1`，结果就为 `1`，非常适合表示已经覆盖的需求集合。

## 7. 状态压缩 DP

定义：

```text
dp[mask] = 覆盖 mask 中这些需求，最少需要的机器数量
```

总共有 `t` 个需求，因此状态数量是 `2^t`。所有需求都满足时的状态为：

```python
full = (1 << t) - 1
```

例如 `t = 3`：

```text
1 << 3     = 1000（二进制）
(1 << 3)-1 = 0111（二进制）
```

初始化时还没有覆盖任何需求：

```python
INF = d + 1
dp = [INF] * (1 << t)
dp[0] = 0
```

`INF` 取 `d + 1` 足够，因为最多只可能选择 `d` 台机器。

## 8. 为什么必须复制一份 DP

处理一台机器时，有两种选择：

1. 不使用这台机器，状态保持不变
2. 使用这台机器，把当前状态与机器覆盖状态做按位或

转移公式是：

```python
new_mask = mask | machine
new_dp[new_mask] = min(new_dp[new_mask], dp[mask] + 1)
```

代码中使用 `new_dp = dp[:]`：

```python
for machine in masks:
    new_dp = dp[:]

    for mask in range(1 << t):
        if dp[mask] == INF:
            continue

        new_mask = mask | machine
        if dp[mask] + 1 < new_dp[new_mask]:
            new_dp[new_mask] = dp[mask] + 1

    dp = new_dp
```

如果直接在同一个 `dp` 上更新，那么当前机器刚刚产生的新状态可能在同一轮再次被使用，等价于重复选择同一台机器。复制数组可以保证一轮只处理一次当前机器。

## 9. 完整代码

```python
import sys


def solve():
    input = sys.stdin.readline

    # d: 机器数量
    # w: 每台机器的条目数
    # t: 业务需要的条目数
    d, w, t = map(int, input().split())

    # 读取所有机器的原始数据
    machines = []
    for _ in range(d):
        machines.append(list(map(int, input().split())))

    # 读取业务需求
    needs = list(map(int, input().split()))

    # 给每个需求条目编号为 0 ~ t - 1
    pos = {}
    for i in range(t):
        pos[needs[i]] = i

    # 将每台机器转换成 bitmask
    masks = []
    for machine in machines:
        mask = 0

        for x in machine:
            if x in pos:
                mask |= 1 << pos[x]

        # 不覆盖任何需求的机器可以忽略
        if mask != 0:
            masks.append(mask)

    # 所有需求都满足时的状态，全为 1
    full = (1 << t) - 1

    # dp[mask]：覆盖 mask 中这些需求，最少需要多少台机器
    INF = d + 1
    dp = [INF] * (1 << t)
    dp[0] = 0

    # 一台一台考虑机器
    for machine in masks:
        # 复制当前状态，避免同一台机器在一轮中被重复使用
        new_dp = dp[:]

        for mask in range(1 << t):
            if dp[mask] == INF:
                continue

            new_mask = mask | machine
            if dp[mask] + 1 < new_dp[new_mask]:
                new_dp[new_mask] = dp[mask] + 1

        dp = new_dp

    # 无法凑齐所有需求
    if dp[full] == INF:
        print(0)
    else:
        print(dp[full])


if __name__ == "__main__":
    solve()
```

## 10. 复杂度

令 `d` 为机器数量，`t` 为需求数量。每台机器需要遍历 `2^t` 个状态，因此时间复杂度为：

```text
O(d × 2^t)
```

DP 数组的空间复杂度为：

```text
O(2^t)
```

这种方法适合需求数量 `t` 较小、机器数量 `d` 较大的场景。状态压缩的关键前提正是：目标集合的大小比原始能力全集小得多。
