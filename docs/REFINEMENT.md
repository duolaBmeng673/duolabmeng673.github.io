## 颜色规则

基于原有冷纸张／深绿灰主题，保留主青绿，减少大面积相近浅绿的弱背景。所有值集中在 `src/styles/global.css` 的 tokens 中。

- 主链接、交互、focus、选中按钮与当前导航：`--accent`／`--accent-strong`，保持青绿色。
- 内容标题：`--heading`，同层级标题统一使用高对比深色／浅色文字，不按文章分类切换颜色。
- 眉题、文章分类文字、检索分类信息与课程编号：统一 `--label: var(--warm)`。亮色暖褐 `#955137`，暗色暖橙 `#e0a17d`；移除了 ACM/OJ 单独覆盖文字颜色的规则。论文和 ACM/OJ 的同类眉题采用同一排版与颜色。
- 暖色的固定辅助位置：精选列表顶边、关注方向小标记、学习模块入口左边界、课程编号、时间线节点、可选文章副标题。模块 hover 使用 `--warm-soft`，保持少量冷暖对比。
- 分类识别仅用文章列表的小圆点，固定映射为论文青绿、技术／算法暖褐、学习中性灰绿，不改变眉题文字或主交互颜色。
- 日期、摘要、计数等辅助信息为中性色；tag 采用中性表面与文字，hover 回到统一青绿色。

亮色暖褐文字与页面背景的计算对比度为 5.54:1，暗色为 7.65:1；正文辅助色对应 4.76:1、6.69:1。这些是选定 tokens 的对比度计算，不代表所有页面均完成无障碍审计。
